# Developing Your First ML Workflow

Coursework for Udacity's Machine Learning Engineer Nanodegree, course 2. The notebooks cover SageMaker training jobs, endpoints, batch and processing jobs, Lambda and Step Functions pipelines, and model monitoring.

## What's inside

- `lesson2/` to `lesson4/` hold the demos and exercises with solutions
- `project/` holds the course project

## How to run

```bash
pip install -r requirements.txt "sagemaker>=2,<3"
```

Open the notebooks in SageMaker Studio or a SageMaker notebook instance.
